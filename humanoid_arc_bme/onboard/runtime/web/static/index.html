Arm

Type to arm . Hold the physical stop. The command starts at zero.

Preflight

    Drive

    Hold to run. The robot moves only while you press the pad or hold a drive key (W/S forward-back, A/D turn, Q/E sideways). Releasing commands zero (the robot stands, still armed). After ARM, release every input once before the first move (a key held across arming is ignored). Leaving this tab or losing the link stops the heartbeat: the robot disarms after the deadman timeout.

    Envelope (config/g1_limits.yaml, S1-narrowed): -

    vx = v, wz = v * kappa. If the yaw rate would exceed the envelope, the speed drops and the curvature is kept. The sliders only shape the path: the robot moves only while HOLD TO RUN is pressed.

    Uses the latest /cmd_vel from the ROS 2 wrapper (zero if older than 0.5 s). The heartbeat from this page is still the deadman.
